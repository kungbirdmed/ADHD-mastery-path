# 🧠 ADHD Mastery Path
> *"Do not try to calm the storm. Learn to command the ship."*

Welcome, Neuro-Curious Explorer.

This is not a list of life hacks.
This is a **neuroscience-based operating manual** for the ADHD brain — designed for self-discovery, deep understanding, and long-term mastery.

This project rejects deficit-based interpretations of ADHD and instead focuses on how brain function, environment, and context shape performance.

---

## 🎯 The Mission: From Coping to Commanding

This project is built on three core pillars:

1. **Self-Discovery & Education**  
   Understand *why* your brain works the way it does using neuroscience (dopamine, norepinephrine, default mode network, executive systems).  
   Stop blaming yourself. Start building yourself.

2. **Environmental Hijacking**  
   Learn how physical, digital, and social environments shape attention, motivation, and regulation.  
   Rewire your surroundings to work *with* your brain — not against it.

3. **Collaborative Truth-Seeking**  
   This is a living knowledge base grounded in science and lived experience.  
   Discussion and shared learning are encouraged; uncredited reuse or derivative work is not.

This path is informed by real-world experience in high-pressure, sensory-intense environments.
